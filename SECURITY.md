# Security Policy

## Supported Versions

Only the latest version deployed to [Render.com](https://generated-game-experiment.onrender.com/) and [GitHub Pages](https://commjoen.github.io/generated-game-experiment/) is actively supported for security updates.

| Version                 | Supported          |
| ----------------------- | ------------------ |
| Latest deployed version | :white_check_mark: |
| Previous versions       | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by:

1. **Opening a GitHub Issue** with the "security" label
2. **Providing detailed information** about the vulnerability, including:
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### Recognition

Upon confirmation of a valid security vulnerability, we will:

- Acknowledge your contribution in the project's documentation
- Provide an **honorary mention** in the repository credits
- Include your name (if desired) in the next release notes

### Response Timeline

As this is a **free, open-source software project** maintained by volunteers:

- Initial response: Best effort within 1-2 weeks
- Fix timeline: Depends on severity and maintainer availability
- We appreciate your patience and understanding

### Scope

This security policy applies to:

- The web application hosted on Render.com and GitHub Pages
- The game client and multiplayer server code
- Dependencies and build processes

Thank you for helping keep this project secure! 🎮
